# Breast Cancer Classification using Supervised Machine Learning

### Project Overview

This project predicts breast cancer using supervised machine learning algorithms. The Breast Cancer dataset from Scikit-learn is used for training and testing different classification models.

### Objective

The objective of this project is to predict breast cancer using machine learning. The data is preprocessed and scaled before training the models. Five classification algorithms are implemented and compared to identify the best-performing model based on accuracy.

### Dataset

The Breast Cancer dataset is obtained from the Scikit-learn library.

* Dataset: Breast Cancer Wisconsin Diagnostic Dataset
* Type: Classification
* Target: Malignant / Benign
* Number of Features: 30

### Algorithms Used

1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier
4. Support Vector Machine (SVM)
5. k-Nearest Neighbors (k-NN)

### Preprocessing

* Checked for missing values
* Split the dataset into training and testing sets
* Applied StandardScaler for feature scaling

### Model Evaluation

The performance of all five models is compared using accuracy score. The model with the highest accuracy is considered the best-performing model for this dataset.

### Technologies Used

* Python
* Jupyter Notebook
* Pandas
* Scikit-learn
* NumPy
* Matplotlib

### Project Workflow

Data Loading → Data Preprocessing → Feature Scaling → Model Training → Prediction → Model Comparison → Best Model Selection

### Conclusion

The project demonstrates how different supervised machine learning classification algorithms can be applied to the Breast Cancer dataset. The models are evaluated and compared to identify the most accurate model for breast cancer classification.
